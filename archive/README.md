# Archive

`2022-jemdoc/` is the previous version of this site: hand-written jemdoc sources,
their generated HTML, `jemdoc.py`, `jemdoc.css`, and the `assets/` folder that held
the old CV, transcripts, course notes, and paper PDFs.

It is kept only for reference and for the links in the new front page's *Notes*
section. Nothing here is edited any more. To restore it, move the folder contents
back to the repository root and push.

Live path: <https://yushengzh.github.io/archive/2022-jemdoc/>
