# Institution logos

Drop one image per institution in this folder, using **exactly these
filenames**. Anything missing simply renders as text, so you can add them
one at a time.

| File | Institution | Where it appears |
| --- | --- | --- |
| `mbzuai.png` | MBZUAI | About, SciGame affiliations |
| `ustc.png` | USTC | About |
| `xidian.png` | Xidian University | About |
| `ntu.png` | NTU Singapore | About |
| `sail.png` | Shanghai AI Laboratory | About, SciGame affiliations |
| `teleai.png` | TeleAI | About, projects |

## Format

- **SVG** is ideal (`mbzuai.svg` also works — see `LOGO_EXT` in
  `src/data/institutions.js`). Otherwise PNG.
- **Transparent background**, square-ish, at least **128×128** for PNG.
- Colour is kept as-is — these are not tinted to match the page.

## Licensing

These are institutional trademarks. Using them on your own page to indicate
affiliation is normal academic practice, but you are redistributing the
files by committing them here. Prefer the institution's own press kit over
a third-party copy, and drop any you are not comfortable republishing.
