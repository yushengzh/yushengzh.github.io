# yushengzh.github.io

Personal homepage of Yusheng Zhao. One static page, no build step, no dependencies:
edit a file, push, and GitHub Pages serves it.

- `index.html` — all page content
- `styles.css` — colours, type, column width
- `favicon.svg` — browser tab icon
- `assets/` — files the page links to (currently `cv.pdf`)
- `archive/2022-jemdoc/` — the previous jemdoc site, kept for reference
- `TUTORIAL.md` — 中文教程：如何编辑、预览与发布

Live: <https://yushengzh.github.io>
